# ✨ Light Studio

Welcome to **Light Studio**, a modern and creative website designed with HTML5 and CSS3.

## 🌟 About the Project

Light Studio is a visually appealing and responsive website that focuses on clean design, attractive layouts, elegant typography, and a smooth user experience.

## 🚀 Features

- Modern and attractive user interface
- Clean and organized layout
- Responsive website design
- Beautiful color combinations
- Smooth hover effects
- Easy navigation
- User-friendly interface

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout

## 📂 Project Structure

```text
Light-Studio/
│
├── index.html
├── style.css
└── images/
```

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the Light Studio website.

## 🎯 Project Objective

The main objective of this project is to demonstrate front-end web development skills using HTML and CSS while creating an attractive and user-friendly website.
